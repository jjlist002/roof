## 2. 시공사례 등록 계획 (다음 작업)

### 전달 방법 (안내한 두 가지 — 사용자 결정 대기)
- **방법 A**: 사진을 `pic/cases/사례이름/` 폴더에 업로드 + 채팅으로 지역/건물 종류/자재/시공 내용/시기 전달 (메모 수준이면 충분, 문구·사진 압축은 Claude가 처리)
- **방법 B**: 네이버 블로그(blog.naver.com/misotechne)에 먼저 글 작성 후 링크 전달 → Claude가 읽어서 페이지 생성

### 구현 방향 (합의된 방식)
- 사례마다 개별 HTML 페이지 (`cases/<slug>.html`) 생성 → 지역+자재 롱테일 키워드로 검색 노출
- 메인 페이지 #portfolio 갤러리에서 사례 페이지로 연결
- sitemap.xml에 사례 페이지 등록
- 사진은 sharp로 웹용 압축 (Cloudflare Pages 25MB 파일 제한 주의)
- 첫 사례 몇 건으로 페이지 디자인 틀부터 잡아서 보여주기로 함
